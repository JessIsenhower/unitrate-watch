# UnitRate Watch

A zero-capital consumer self-storage price-transparency experiment.

## Beta product
A renter supplies only:
- current facility or ZIP
- current monthly base rent
- unit size
- unit type

UnitRate Watch does the comparison work: current public rates, comparable-unit caveats, and a stay / negotiate / switch recommendation.

## Current launch state
The public site is ready for GitHub Pages. The rate-scan CTA still needs a dedicated business inbox before accepting requests.

## Guardrails
- Do not claim a large rent increase is illegal merely because it is large.
- Do not present promotional/non-comparable rates as equivalent.
- State uncertainty and source current pricing.
- Disclose future affiliate relationships clearly.
- Do not add paid APIs before demand is demonstrated.
